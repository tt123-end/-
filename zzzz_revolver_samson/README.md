# 猎手 Hunter — v1.72

本版修复初始射速/上限偏低，以及萌死戳的肺、硫磺火、胎儿博士仍施加原生射速惩罚的问题。基础泪属性使用原生的完整分段公式，初始射速为0.48、普通射速上限为1；这三个道具的缓存武器类型只在同步数值重算时屏蔽，结束/异常后恢复，不更换武器对象，也不改变攻击方式、伤害规则和UI。保留v1.71不依赖debug库的修复。

测试加入负泪属性分段、缓存武器惩罚及状态恢复的模型，旧版在两组回归中分别失败，新版通过；本机未运行Isaac游戏。

基于已确认的v1.69精简包。本版只调整里猎手指定道具的属性与相关飞刀效果，保留当前人物/UI和其他已确认机制。需要当前忏悔+对应的REPENTOGON。

## 射速规则

取消原先的负射速倍率补偿，不再有趋近0.6的保底，也取消吐根＋胎儿博士固定0.6上限。固有射速倍率仍为×0.2；初始无道具数值仍为射速0.48、普通上限1、面板伤害4.2、弹速1.6、射程12。

下表中的道具不再施加其原生射速修正降低；没列出的其他道具按原规则结算，不享受原先的负倍率补偿。旧射速补偿/采样模块已从精简包删除。

| 道具 | 新属性与效果 |
|---|---|
| 内眼 | 保留当前三发，伤害×0.5 |
| 变异蜘蛛 | 保留当前四发，伤害×0.42 |
| 科技2 | 保留当前攻击，伤害倍率改为×0.75，不额外叠加原生降伤 |
| 巨人独眼 | 替换原生伤害加成，仅+8基础攻击力；无原生伤害倍率；飞刀获得真正穿透，移除原先剩余伤害型伪穿透 |
| 萌死戳的肺 | 当前散弹方式保留，伤害×0.23 |
| 夏娃的睫毛膏 | 仅伤害×1.35，取消原生×2及弹速降低；改为弹速上限2 |
| 硫磺火 | 当前飞刀＋硫磺火攻击与伤害兼容保留，仅取消原生射速惩罚 |
| 胎儿博士 | 当前飞刀/爆炸方式保留，伤害×0.8；主刀基础仍为400%面板，爆炸仍为2×面板＋30 |
| 吐根 | 当前直线飞刀/命中爆炸保留，移除原生+40面板攻击力；主刀和爆炸均为2×面板＋40 |
| 泪血症 | 当前攻击方式保留；替换原生伤害加成，改为+3基础攻击力，不叠加原生1.5倍伤害 |

伤害倍率按每种道具是否生效计算一次。基础攻击力加值进入伤害加法阶段，再按角色及其他道具倍率结算；例如单独持有巨人独眼、无其他增伤时是(3.5+8)×1.2=13.8面板伤害，单独泪血症为(3.5+3)×1.2=7.8。额外副本/临时效果的基础加值按数量计算；倍率不因同一种道具额外副本重复叠乘。

## 已确认的组合规则

- 内眼、变异蜘蛛、萌死戳的肺任意组合只取最低伤害倍率。三者同时拥有时为×0.23，不把×0.5、×0.42、×0.23叠乘；与这组无关的倍率正常相乘。
- 有完美视力时取消上述三种道具的伤害惩罚；完美视力本身的原生×0.8仍保留。
- 同时有完美视力与巨人独眼时，完美视力的原生×0.8也取消。
- 同时有吐根与胎儿博士时，保留爆炸免疫，取消博士×0.8，主刀与爆炸均为2×面板＋40，不额外加博士的30。
- 巨人独眼的真穿透会作用于飞刀及其相关分裂弹。带爆炸的真穿透飞刀命中敌人后仍继续飞行，沿用现有单次爆炸记录，避免同一飞刀重复引爆；墙体/射程处理保持原规则。

以上为基础伤害公式；巧克力牛奶等其他已确认兼容的额外作用继续按原规则结算。

## 显示与安装

Stats+的原生伤害倍率条目已替换为新规则，包含最低散射倍率、完美视力与巨人独眼例外，避免原生倍率和新倍率重复显示。保留射速×0.2显示并修正受影响的射速上限显示。EID角色特性及相关道具中英文说明同步。

完全退出游戏，先把旧zzzz_revolver_samson文件夹移出mods备份，再完整解压本包同名文件夹，只启用一份猎手。完整替换会移除旧的射速补偿文件；不要删除游戏data目录或自己的存档。通过匹配忏悔+的REPENTOGON Launcher启动，先开测试局，hunterdiag应显示[Hunter v1.72] REPENTOGON=true，并报告当前伤害、道具倍率、射速、上限及弹速。
