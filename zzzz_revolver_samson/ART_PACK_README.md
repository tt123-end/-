# v1.79-art 安装及验证

适用：忏悔+、匹配版本的REPENTOGON、里猎手。本版参照上传视频重做飞行套装的原版风格短羽翼，保留14种套装、66项道具造型、边缘补全、死亡之眼隐藏与旧衣柜兼容。

完全退出游戏，将旧猎手和旧衣柜文件夹移出mods备份，再把安装包内的zzzz_revolver_samson和old wardrobe_2488945061两个文件夹放入mods。只启用各一份，避免创意工坊更新的原版旧衣柜覆盖兼容脚本。EID和Stats+继续使用原本安装的版本，无需替换这两个辅助Mod。

十四种造型：嗝屁、蝇王、真菌、炽天使、鲍勃、药物过量、妈宝、连体婴、利维坦、大便套装、书虫、成人、蜘蛛宝宝、践踏。另对未用于正常游戏的Flight引擎枚举提供备用造型，不作为额外的正常套装列入衣柜。

飞行套装背部采用同样的原版风格短羽翼，按套装着色：嗝屁粉白羽翼、蝇王青绿羽翼、炽天使暖白羽翼、利维坦紫色羽翼。六姿态采用40游戏更新帧循环，约1.33秒，站立和蓄力时持续收放；下垂时露在身体两侧下方，上扬时被头部自然遮挡；侧面只绘制近侧一翼。跟随身体锚点、朝向、缩放和颜色，绘制在身体与头部后方。衣柜预览使用同一绘制方法。死亡、幽灵、不可见及不适用的特殊动画不绘制。

衣柜左侧列表增加82项：HUNTER: Automatic / restore恢复自动并取消隐藏；HUNTER: Original appearance恢复原外观；14项FORM选择套装，66项ITEM选择道具造型。使用键穿上、药丸/卡牌键脱下、炸弹键恢复原外观。飞行套装只允许已有飞行能力的角色手动选用。原道具/套装网格中的开关也会同步猎手造型。

显示顺序：衣柜手动选择优先；自动时最近形成且未隐藏的套装优先；没有可见套装时采用原道具优先级（哭泣优先，硫磺火/巴比伦/钉子次之，其余按最近获得）。整合头部显示一种，避免多个脸/帽子穿插；拥有多种飞行套装时显示一对翅膀，优先匹配手选的飞行造型，否则取最近形成且未隐藏的飞行套装。选择、隐藏与已观察到的形成顺序保留到续关；新局恢复自动。

道具/套装的实际拥有、游戏效果、生命、伤害、飞行与Stats+数值由原玩法控制。换装只影响外观。EID同步中英文人物说明与道具外观的优先级说明。373死亡之眼继续隐藏人物服装，保留原道具和连击增伤。

调试控制台输入hunterartdiag可查看外观版本、当前造型、套装、翅膀和衣柜模式；hunterdiag仍为原玩法的数值诊断。

验证命令为python3 tools/test_dynamic_art.py（仓库根目录）。离线检查覆盖Lua、66项原造型、14种套装和备用枚举、实际旧衣柜脚本的列表/网格/预览/批量操作、存档、四向六帧翅膀、资源和坐标。所有套装按正常人物的脸部轮廓中心和下巴逐状态定位，身体、碰撞体和动作时序保留；完整图格有透明边距。

此云环境没有Isaac游戏程序，尚未游戏实测。预览由真实ANM2和贴图离线合成，不是游戏截图。游戏内建议核对四种飞行套装站立/射击/四向移动，衣柜逐项穿脱/恢复自动，以及退出续关、死亡复活和多人状态。

旧衣柜兼容目标是用户上传的Old Wardrobe v1.16（2488945061，Sinsthar），本包附完整兼容版本；未验证Wardrobe Plus。旧衣柜原脚本的衣柜生成、计时等原行为保留。详细改动与可重现补丁见仓库docs和tools/patch_old_wardrobe.py。

猎手与原玩法来自用户上传项目；既有三项连续粒子借用用户上传Marisa as Cain参考；新增头部与翅膀图集由图像生成工具参照猎手原画制作。头部图集及定位数据位于art_sources/transformations178；新羽翼源图、视频关键帧、40帧时序与挂接记录位于art_sources/wings179，可重新装配及复查。

常见原版白翼来源（如命运、圣经实际生效时等）在定制羽翼显示期间隐藏服装，避免重复翅膀；切回原外观/非猎手后恢复仍有效的原版服装。不移除道具，不修改飞行或效果计数。
