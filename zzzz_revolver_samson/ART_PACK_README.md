# v1.77-art 安装及验证

此包替换v1.73全部静态贴片。先完全退出游戏，移走旧猎手文件夹备份，再解压完整包；只启用一份猎手，使用忏悔+对应的REPENTOGON启动。

本版66项为整合头部/颈部造型，每项含六幅方向与待机/射击状态。左向由右向镜像。饰物不再以通用坐标压到脸上。悲伤洋葱另有三帧泪滴循环；炸弹引线、蓝蘑菇各有四帧循环。连续特效沿用参考Mod的分层动画，不把所有饰物都做成无意义抖动。

组合规则：哭泣优先；硫磺火/巴比伦/钉子次之；同优先级按最近获得显示一种。整张脸和帽子不相互叠加。并非每个道具造型都同时显示。玩家之间状态独立。持续型主动以原生临时效果为准；39/49/123/126只显示短暂使用反应。

EID追加中英文说明，原玩法和Stats+数值模块保留。hunterdiag仍用于原v1.72数值诊断；hunterartdiag用于v1.74外观诊断。

测试方法：先开测试局，分别生成悲伤洋葱、硫磺火、矿工帽、蓝蘑菇等，观察待机/连续射击/四方向/拾取/受伤及丢弃/重置后的恢复，再检查组合。无需删除存档。

离线检查覆盖Lua/资源/实际帧像素/状态恢复，并提供按ANM2坐标合成的动态预览。尚未进行Isaac游戏实测；预览不是游戏截图。变身和死亡使用原人物的专门动画；死亡时暂停额外循环，复活后恢复。仍需在游戏中验证服装引擎实际挂接、道具组合和继续游戏。

位置修正：各道具造型使用各自的枢轴表，清除造型时恢复原表。切换保留当前动作帧、头部叠加帧、缩放和颜色，不移动身体或碰撞体。

v1.76位置校准：使用各造型各状态自己的脸部轮廓定位，取代v1.75统一偏移。数据记录在art_sources/head_landmarks176.json。角色正常状态仍使用原v153动画。全套坐标经离线原生缩放/镜像/动作曲线检查，尚未游戏内验收。同时补全源图集中被裁切边界截到的脸部图格，再进行轮廓定位。

v1.77：所有方向/动作图格增加透明边距，补回帽灯、角、翅膀被图格边界截掉的部分，延续v1.76的脸部定位。只隐藏里猎手的死亡之眼人物服装，持有道具及连击/伤害效果保留。请完全退出游戏并完整替换旧文件夹，避免旧贴图缓存。
