# 里猎手 1.73-art 外观包

完整包以用户上传的猎手 v1.72 为基础。新增66项道具外观及对应中英文EID说明，原有战斗和Stats+数值模块保持原文件内容。

安装：完全退出游戏，将旧猎手文件夹移出mods备份，再把本包的zzzz_revolver_samson放入mods。只启用一份猎手。使用忏悔+对应的REPENTOGON启动。无需修改EID或Stats+的文件。

美术：深绿、骨白、皮革、银铜金属和红宝石。每项使用256px透明方向帧；正面、右侧、背面独立素材，左侧镜像。源图集随开发资料包保存。以里猎手原动画的位移、缩放、时序驱动配饰，不改变角色碰撞体积。

这版采用独立服装叠加，不替换整张角色脸。部分参考Mod原先隐藏的装饰在此重新设计，例如幸运脚的兔骨胸针、生长激素的皮甲。主动效果通过原生临时效果和使用事件触发。普通持续型主动在换房时清除，短时主动有显示计时。

验证：Lua5.4语法、XML/ANM2解析、资源路径、裁切边界和模拟状态检查；模拟覆盖双人、移除道具、主动触发、角色切换、白火游魂、巧克力牛奶替代道具及EID追加。合成预览由动画坐标离线绘制，不是游戏截图。

本环境没有Isaac运行程序，尚未在游戏里逐项验收。需要实测服装叠加顺序、服装被引擎重建、飞行/死亡/特殊动画、主动道具增时组合和中途继续游戏。合成预览不能证明引擎实际服装挂接结果。请先用测试局检查；该版本为可安装的外观测试版。

参照：用户提供的Marisa as Cain v1.16用于道具覆盖范围及服装组织方式参考；新配饰由图像生成工具按里猎手主题设计。原人物资源和玩法代码沿用用户上传包。
