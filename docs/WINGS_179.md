# v1.79：按用户视频重做羽翼

参考为用户上传的20261029-1638-29.8007924.mp4，862×638、30fps、约22.27秒。视频约5.2秒到6.3秒可见六个主要轮廓：向下舒展、内收、紧收、向上藏在头后、水平回展、弯曲下拍；相邻完整周期约1.3至1.4秒。视频关键帧及像素分类记录保存于art_sources/wings179，不包含完整录屏。

本次参照视频重新生成短羽毛轮廓，使用简单的黑褐外框和浅色羽片。正面/背面各一对，左右侧面各一只；不再使用旧版装饰性大翼或将双翼挤窄充当侧视图。四个飞行套装使用相同的原版风格动作，分别由游戏颜色接口呈现粉白、青绿、暖白及紫色。

六姿态延时为10、7、3、10、5、5个游戏更新帧，总40帧；按30更新/秒约1.33秒。此时序是按录屏观感制作的适配，不声称读取了原版游戏的ANM2。贴图是参考后重绘，也不是从游戏文件提取的原版贴图。

新部件在256像素透明图格内按各自根部挂接，固定在身体下背部；使用原人物动作曲线，标准站立锚点为(0,-3.6)。这一位置来自原身体图格中y80的部位，代替旧版靠近颈部的y64。向下羽翼伸出身体下方，向上的轮廓自然被头部/头发遮住，侧面仅一翼。不会改变人物头部、身体、碰撞体或攻击动作。

四套配色通过Color乘法与角色原本颜色组合，保留透明度、受伤颜色等原效果。动作按游戏时间推进，走路帧保持0时仍持续收放，暂停时停在当前帧。旧衣柜预览直接复用游戏内的绘制函数。

命运、圣经实际使用效果等常见原版羽翼来源在定制服装显示时只移除服装，避免双层白翼；隐藏定制羽翼或更换角色时恢复仍有效的原版服装。不改道具、飞行能力或效果计数。

复现：python3 tools/build_native_wings.py。头部整体重建tools/build_transformations.py也会调用新羽翼装配，不会重新生成旧版大翼。新运行资源位于zzzz_revolver_samson/resources/gfx/characters/hunter_wings179，旧版wings_*已从安装包移除。

验证：python3 tools/test_dynamic_art.py。检查四向部件数量、六个真实不同姿态、固定根部、尺寸/透明边距、40帧时序、向上遮挡与向下伸出身体的位置、颜色组合、原版羽翼去重/恢复，以及原有66项道具、14种套装、续关和实际旧衣柜脚本的列表/网格/预览。预览是离线合成，本环境没有Isaac运行程序，尚未游戏内实测。
