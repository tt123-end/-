# v1.80：针对用户录屏的外观回归修复

本次同时处理全身红/蓝、羽翼位于脚部、静止踏步与道具持续特效失效。头部/身体贴图、已校准的脸部坐标与原有玩法保留。

- 颜色：移除渲染路径中的Color对象乘法。按RGBA、Offset和Colorize数值构造新的颜色对象，仅对羽翼的独立Tint着色。循环着色不再读改写角色持有的颜色对象，也不重置合法的受伤/透明颜色。
- 位置：羽翼挂点由身体源图y80改为y58，标准坐标从(0,-3.6)上移至(0,-10.2)。人物头部、身体和碰撞位置不动；衣柜预览使用相同位置。
- 静止：旧分支在没有射击输入时提前返回。现在所有普通行走朝向都根据实际速度判断停步，使用REPENTOGON的Stop(false)只停身体，移动后Continue(false)恢复。头部、射击、拾取、受伤和死亡轨道保留。
- 换图：在任何服装清理和图形重绑前保存主轨/头部轨的帧、播放状态、缩放、颜色等数值，换图后恢复。头部轨使用整数SetOverlayFrame，避免命名重选造成停播。
- 持续效果：悲伤洋葱泪滴、炸弹引线火花和蓝蘑菇粒子不再依赖原生Null服装挂接，改为独立Sprite与游戏时钟。停步、换图、续关和衣柜切换不会让它们停在一帧；死亡/幽灵/特殊形态时隐藏。泪滴宽度和侧面位置、火花与实际引线火苗的挂点重新校准。
- 衣柜：增加头部前景粒子的预览调用，与房间内共用绘制方法；安装包包含完整兼容版。

运行python3 tools/test_dynamic_art.py，检查10000次颜色绘制、全部66项真实视觉回调的静止/射击/移动/拾取、两条动画轨道在换图后的恢复、三种粒子的四个朝向、暂停时钟、生命周期、组合与实际旧衣柜脚本。像素检查还覆盖原有396幅道具图格、套装图格、透明边距和上背部羽翼遮挡。

参考接口：REPENTOGON公开LuaSprite.cpp中Stop(false)/Continue(false)分别只操作主轨；LuaColor.cpp中GetColorize返回R/G/B/A字段，扩展Color构造函数支持复制这些数值。本修复不依赖颜色乘法是否返回新的userdata。
