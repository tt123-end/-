# 旧衣柜：猎手兼容版 v1.78

本文件夹来自用户上传的 Old Wardrobe（创意工坊2488945061，作者Sinsthar）。保留原作者的UI、资源、物品和衣柜逻辑。仅在main.lua增加可选的猎手换装接口与翅膀预览；猎手未启用或正在为其他角色换装时，使用原逻辑。

安装时完全退出游戏，以本文件夹替换原“old wardrobe_2488945061”，不要同时启用两份旧衣柜。与猎手v1.78一起使用。无需修改EID或Stats+。

打开衣柜，切到左侧列表，即可找到 HUNTER 项：Automatic / restore 恢复自动显示并取消隐藏；Original appearance 使用原外观；H-Form为14种套装；H-Item为66种已适配道具。使用键穿上、药丸/卡牌键脱下、炸弹键恢复原外观。飞行套装的手动选择沿用衣柜原有限制：角色已有飞行能力才可选择；不授予飞行。

原道具/套装网格中的开关也会同步到猎手。手动选择优先于自动；自动时最近形成的可见套装优先，其次为原道具优先级。多个飞行变身同时存在时显示一对翅膀，优先与手选套装对应，否则采用最近形成且未隐藏的飞行套装。造型选择、隐藏与形成顺序保存在猎手自己的续关数据中。

嗝屁为粉白膜翅、蝇王为青蓝虫翅、炽天使为白金羽翼、利维坦为紫黑蝠翼。六帧循环独立于走路和射击，站立时持续扇动；房间与衣柜预览共用绘制方法。死亡、幽灵和特殊不可见状态隐藏翅膀。

这项适配不改道具、套装判定、飞行能力、伤害、生命或Stats+数值。衣柜原有的地图/计时等行为由原Mod控制，未在本次适配中扩展。未包含Wardrobe Plus的专用适配；目标为上传的旧衣柜版本。

离线接口测试与资源检查不能代替游戏实测。可在控制台输入hunterartdiag查看当前套装、翅膀与选择模式。
