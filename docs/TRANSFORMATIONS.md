# 里猎手 v1.80 套装外观

本版覆盖14个正常游戏使用的角色变身。PlayerForm是游戏的角色套装判定，造型选择不会改变该判定或效果。头部包含正面、侧面、背面的待机/射击状态，左向镜像；完整透明边距保留角、帽檐、光环等外轮廓。每种按正常猎手的脸部中心/下巴逐状态定位。

引擎还定义了未用于正常游戏的PLAYERFORM_FLIGHT（14），本版提供翡翠羽饰与备用翡翠色羽翼，防止其他脚本启用它时缺少资源；不把它列为正常套装或衣柜选项。超级乞丐是跟班合成，不属于角色PlayerForm，不替换玩家头部。

多个套装同时生效时，完整头部采用最近形成且未隐藏的一种；通过衣柜手动选择可覆盖自动顺序。多个飞行套装同时存在时，使用一对翅膀，优先匹配手选飞行套装，否则取最近形成且未隐藏的飞行套装。手选非飞行套装/道具不会抹除已有飞行套装的翅膀；选择原外观可以隐藏全部定制服装。

旧衣柜左侧列表可以直接选套装/道具，原网格开关也有效。飞行造型仅对已有飞行的角色开放，不授予飞行。需要安装本包附带的旧衣柜兼容版；详情见OLD_WARDROBE_COMPAT.md。

头部源图为art_sources/transformations178/heads*.png；新羽翼源图和视频参考位于art_sources/wings179。存在原图边缘接触的两行已重新生成，装配使用heads_repaired.png中的完整行。裁切使用整张源图的透明轮廓分割，避免旧版128像素格子截断；实际动画使用256像素透明画布。人脸位置与翅膀挂接数据分别保存在对应源图目录。

预览为离线合成，尚未在Isaac中实测。验证工具检查15套引擎资源（14个正常变身及1个备用）、90幅方向/动作图格、四套配色、四朝向六个收放姿态、36个固定根部部件与40帧时序，以及旧衣柜实际脚本的接口行为。
