## v1.80 颜色、停步与道具动态

羽翼和粒子每次从人物颜色的数值构造独立颜色对象，不再将人物持有的颜色对象带入乘法；只给羽翼着色，保留人物的透明度与合法颜色效果。连续10000次绘制的回归检查验证人物颜色不变。

羽翼挂点上移至背部偏上，标准位置从(0,-3.6)调整为(0,-10.2)。只改变羽翼挂点，头部、身体、碰撞体和原画不移动。站立时停止身体轨道，头部/射击轨道继续由游戏控制；开始移动会恢复走路，拾取、受伤、死亡等动作保留。

悲伤洋葱、炸弹引线和蓝蘑菇粒子改用独立Sprite与游戏时钟，不依赖换图时可能失效的原生服装挂接。泪滴和引线火花重新校对挂点；旧衣柜预览复用相同绘制函数。所有66项外观均检查停步/恢复移动、射击头部轨道和换图后的播放状态。

## v1.79 视频参考羽翼

四种飞行套装统一采用视频中的原版风格短羽翼：黑褐轮廓、少量羽毛分叉，去掉旧版的大幅展翼、膜翅/蝠翼与中央饰物。嗝屁粉白、蝇王青绿、炽天使暖白、利维坦紫色。侧面有单独绘制的一只近侧翅膀，正面与背面显示成对羽翼。

六个姿态依次为下垂、内收、紧收、上扬至头后、水平回展、弯曲下拍，采用40个游戏更新帧循环（约1.33秒）。按视频调整到下背部，向下时露出身体两侧/下方，向上时被头部与头发自然遮挡。身体、头部贴图与坐标保持v1.78结果。衣柜预览使用同一轮廓、时序、颜色和位置。

同时对圣经实际使用效果、命运等常见原版羽翼来源进行外观去重，避免原版白翼与套装羽翼叠加；解除定制飞行外观时恢复仍有效的原版服装。道具、套装效果和飞行能力保留。

## v1.78 套装外观与旧衣柜

四种飞行套装各有六帧独立扇动：嗝屁粉白羽翼、蝇王青绿羽翼、炽天使暖白羽翼、利维坦紫色羽翼。四个朝向均有动画，站立和蓄力不依赖走路帧，位于身体/头部后方；衣柜预览采用同一绘制接口。

## v1.76逐项位置校准

撤销v1.75统一使用的(8,7)头部偏移。66项造型现在各自拥有六个方向/动作状态的坐标表，以正常人物的脸部轮廓中心和下巴为参照，正面、侧面、待机和射击分别计算。帽子、角、灯和装饰不作为定位依据；被绷带遮挡的脸部使用单独记录的轮廓点。

例如荆棘造型（殉道者之血）的正面待机修正由统一(8,7)改为(3.5,4)源贴图像素；射击、左右朝向另有对应值。数据见art_sources/head_landmarks176.json，生成工具为tools/measure_head_landmarks.py和tools/align_head_anchors.py。

所有新坐标保持身体与碰撞体不动，拾取/受伤/举物复用对应表情的坐标，左向镜像按原生缩放处理。循环粒子同步跟随各自造型。清除道具造型后恢复原人物动画。

## 原外观重做

悲伤洋葱替换整张脸的含泪眼睛和张嘴表情，使用三幅独立泪滴帧循环。炸弹引线和蓝蘑菇采用四帧循环。其余道具按参考Mod的处理思路，提供正面/侧面/背面的待机和射击状态，并使用原人物动作曲线。

饰物、头发、脸和兜帽合并绘制，移除旧版悬空配件，按原头顶/下巴边界对齐。拾取、举物、使用道具和受伤动作的头部也使用新造型；动作本身的时序与位移保留。

没有套装或衣柜手动选择时，道具同槽位采用一种整合造型：悲伤洋葱优先，硫磺火/巴比伦/钉子次之，其余按最近获得显示。此规则避免多张完整脸/帽子穿插，组合不会把所有造型同时叠加。持续型主动依赖游戏临时效果，短时使用反应有单独显示。

EID中英文说明同步，支持巧克力牛奶隐藏替代道具。Stats+数值接口与原玩法保留。调试控制台输入hunterartdiag可查看外观版本和当前造型。

## 美术来源与制作

原角色/玩法来自用户上传的猎手v1.72。新整合头部图集由图像生成工具参照原人物制作；图集裁切时仅保留主体，清除相邻帧残片。泪滴、引线与蓝蘑菇循环素材及动画结构借用用户提供的Marisa as Cain v1.16（Cordelia、Vd65_63RUS及其贡献者），并按猎手挂接调整。未打包EID/Stats+本体。

原始图集和循环源文件见art_sources；新羽翼源图、参考关键帧、时序与挂接数据见art_sources/wings179。制作依赖：Python3、Pillow、NumPy、SciPy、ImageMagick；运行时模拟检查使用Lua5.4共享库。执行 `python3 tools/build_dynamic_art.py` 装配全部资源（已存在的道具头部PNG保留；重新装配前删除hunter_art174中的数字命名PNG）；新增套装可单独执行python3 tools/build_transformations.py。
